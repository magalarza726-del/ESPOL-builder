# v0.16 — Día / Noche

La interfaz pública se reduce a dos modalidades:

- Día: Shift ×5 y jetpack manteniendo Espacio.
- Noche: iluminación oscura, linterna con F y pistola con clic izquierdo.

Internamente se reutilizan los controladores ya estabilizados de RPG (jetpack) y Shooter/Terror (arma, apuntado, iluminación y linterna). No se duplica terreno, bosque, colisión ni lógica de mundo.
