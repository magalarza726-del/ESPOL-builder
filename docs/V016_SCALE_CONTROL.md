# v0.16 — Guardas de escala FIMCP

La red de control espacial fija relaciones métricas entre puntos cartográficos de FIMCP y bloquea regresiones severas de escala.

Rangos de prueba actuales:
- parqueadero ↔ Auditorio: 45–85 m;
- Auditorio ↔ Bloque 18-A: 35–75 m;
- Bloque 18-A ↔ 24C: 80–135 m;
- 24C ↔ Terminal: 35–80 m;
- parqueadero ↔ Terminal: <260 m.

Estos rangos no sustituyen un levantamiento topográfico; son guardas de integración suficientemente estrictas para impedir que una inferencia fotográfica vuelva a separar el conjunto por factores del orden de 20×.
